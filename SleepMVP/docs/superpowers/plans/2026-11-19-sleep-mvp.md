# 폰을 먼저 재운다 MVP Implementation Plan

**Goal** 1시간 앱 제한과 무료 베타의 7일 재사용률을 검증한다.

**Architecture** SwiftUI 앱에서 FamilyControls 권한과 개별 앱 선택을 처리한다. DeviceActivity 확장이 App Group에 저장한 종료 시각을 확인하고 ManagedSettings 제한을 해제한다. 베타 보고서는 동의 후 수동으로 공유한다.

**Tech Stack** iOS 17, SwiftUI, Screen Time API, XcodeGen, Python 3.

**Spec** 모든 기능 무료. 1시간 고정. 참가자의 첫 제한 시작 후 168시간 내 재사용률 측정.

- [ ] 집계 테스트로 중복, 미성숙 참가자, 재사용 경계, 무응답을 검증한다.
- [ ] 집계기를 구현하고 테스트한다.
- [ ] 앱과 확장을 작성하고 XcodeGen 프로젝트 및 권한 설정을 연결한다.
- [ ] 빌드 가능한 환경에서는 Xcode 빌드와 실기기 테스트를 시행한다. 별도로 집계 테스트와 파일 형식을 확인한다.
