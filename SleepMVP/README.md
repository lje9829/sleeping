# 폰을 먼저 재운다

iPhone MVP 1차 초안 · 2026-11-19

## 제품과 사업

잠들기 직전 릴스나 쇼츠를 보다가 취침을 미루는 대학생과 20대가 첫 고객이다. 스크린 타임 권한을 허용하고 제한할 앱을 한 번 고르면, 다음부터 ‘폰 재우기’ 버튼 한 번으로 1시간 제한을 시작한다. 해제 예정 시각을 표시하고, 사용자가 원하면 즉시 해제할 수 있다. 모든 기능을 무료로 제공한다.

첫 베타의 목표는 일회성 호기심이 재사용으로 이어지는지 확인하는 것이다. 참가자는 계정 없이 써 볼 수 있다. 베타 기록에 동의하면 기기에서 최초 두 번의 제한 시작 시각을 기록한다. 참가자가 공유 버튼을 눌러 직접 전달한다. 권한을 허용하거나 앱 화면을 여는 것만으로는 사용으로 집계하지 않는다.

## 베타 운영과 집계

1. 취침 전에 숏폼을 자주 보는 대학생과 20대를 모집한다. 기록에 참여할 사람에게 첫 사용 전에 무료 베타 기록 동의를 켜도록 안내한다.
2. 첫 제한 시작 직후 한 번, 첫 시작 후 168시간이 경과하면 한 번 더 앱의 ‘베타 기록 공유’에서 보낸 CSV 내용을 받는다. 중간 사용 독려 없이 지켜본다.
3. 받는 사람은 보고서 헤더 하나와 모든 데이터 행을 UTF-8 CSV 하나에 모은다. 같은 참여 번호의 여러 보고서는 그대로 두어도 된다.
4. 프로젝트 폴더에서 `python3 Beta/retention.py reports.csv`를 실행한다.

7일 재사용률은 **첫 제한 시작 후 168시간 이내에 두 번째 제한을 시작한 참가자 ÷ 7일 관찰 결과를 확인한 참가자**다. 첫 사용 후 7일이 지나기 전에는 집계에 넣지 않는다. 첫 보고서를 받은 뒤 후속 결과가 확인되지 않은 참가자는 별도로 표시한다. 최초 보고서도 보내지 않은 참가자는 CSV에 없으므로, 모집 인원과 첫 보고서 수를 함께 기록한다. 한 사람당 한 기기를 기준으로 한다.

## Xcode로 실행

- macOS, Xcode 15 이상, XcodeGen, iOS 17 이상 iPhone이 필요하다.
- Apple Developer 팀에서 앱과 확장용 Bundle ID 및 App Group을 등록한다. `project.yml`의 `BASE_BUNDLE_ID`와 `APP_GROUP_IDENTIFIER`를 해당 값으로 바꾼다.
- `xcodegen generate`를 실행하고 `SleepFirst.xcodeproj`를 연다. 앱과 확장 양쪽의 Signing & Capabilities에서 같은 개발 팀을 지정한다. 두 타깃 모두 Family Controls와 같은 App Group이 필요하다. TestFlight 배포에는 두 타깃의 Family Controls 배포 권한이 필요하다.
- `SleepFirst` 스킴을 선택하고 연결된 iPhone에서 실행한다.

## 첫 실기기 확인 항목

- 스크린 타임 권한 거부 및 재승인, 앱 선택 유지, 앱 미선택 상태에서 시작 차단
- 선택한 앱의 즉시 제한, 선택하지 않은 앱에 접근 가능, 즉시 해제 후 재시작
- 앱이 백그라운드에 있거나 종료됐을 때의 자동 해제, 자정을 넘기는 제한
- 전화와 시계를 선택하지 않은 상태에서 전화 접근 및 기존 알람 동작 확인. 긴급전화는 실제 발신 없이 접근 경로를 확인한다.
- 베타 참여 동의 여부에 따른 기록과 공유, 동의 해제 시 기기 기록 삭제

iOS의 선택 화면은 앱 토큰을 반환한다. 초안은 카테고리 전체 제한을 적용하지 않으며, 전화와 시계가 개별 선택에 들어가지 않도록 화면에 안내한다. 사업 집계 코드는 `python3 -m unittest discover -s Tests`로 검증할 수 있다. Xcode 빌드, 서명, Screen Time 권한, 자동 해제는 실기기에서 확인해야 한다.
